## 补充产品

知道一个已经停运的 AI 产品？**[把它加入清单](https://github.com/leontloveless/dead-ai-products/issues/new?template=product.yml)。**

在英文表单中提供**产品名称**和**相关链接**即可，官网或其他有用的页面都可以。简短介绍可选。资料核验、日期、分类和翻译由我们处理。

也可以通过 PR 向 [data/products/](data/products/) 添加 JSON 文件，只需英文 `name`、`website` 和可选的 `description`。格式见[贡献说明](CONTRIBUTING.zh-CN.md)。

## 关于数字往事

[We Used This · 数字往事](https://weusedthis.com/zh/)保存产品历史和人们与它们有关的回忆。本仓库维护基础产品清单；完整档案、来源和翻译由我们在网站项目中维护。
