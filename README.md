## Add a product

Know an AI product that shut down or announced a closure? **[Add it to the list](https://github.com/leontloveless/dead-ai-products/issues/new?template=product.yml).**

Share its **name** and a **link** to its website or another useful page. A short description is optional. We'll handle the research, dates, categories and translations.

Prefer a pull request? Add a JSON file with `name`, `website` and an optional `description` in [data/products/](data/products/). See [Contributing](CONTRIBUTING.md) for the format. When adding an entry, update the list and entry count in both README versions.

## About We Used This

[We Used This](https://weusedthis.com/) is the companion archive for product histories and people’s memories of using them. This repository keeps the basic product list; we maintain the full records, sources and translations in the website project.
